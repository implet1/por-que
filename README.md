# por-que

This project is my personal test for web scraping using Python. Includes complete with built-in error handling and structured data exporting.

## ✨ Features
* **Targeted Scraping:** Extracts page titles, main headings (H1-H3), and all hyperlinks.
* **Robust Error Handling:** Safely manages connection timeouts, invalid URLs, and HTTP errors.
* **Structured Exporting:** Automatically formats and saves extracted data into a clean text file.
* **User-Agent Spoofing:** Includes rotating/standard headers to mimic legitimate browser requests.

## 🚀 Getting Started

### Prerequisites
Make sure you have Python 3.8+ installed on your system.

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com
   cd por-que
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## 🛠️ Usage
Run the main script from your terminal:
```bash
python scraper.py
```
Enter any valid public URL when prompted to extract its structural data.
